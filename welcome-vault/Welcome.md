# Welcome to MDVR

This is the bundled demo vault. It is small on purpose: enough to prove the
reader works without becoming another project to maintain.

## Start
- [[Getting-Started]]
- [[Vault Map]]
- [[Research/media-test]]
- [[Roadmap]]

## What to Try
- Open a note from Home.
- Search for `Archive` and confirm files inside that folder stay visible.
- Open [[Research/media-test]] to verify image and PDF rendering.
- Select both `demo` and `obsidian` in Settings to see the multi-vault tree.

## Permissions
The demo vault is writable and delete-enabled for testing. The `obsidian` vault
example is read-only, so file actions should disappear there.
